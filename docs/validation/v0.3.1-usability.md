# v0.3.1 usability validation

## Scope

This patch release addresses investigation usability and browser-local continuity:

- unavailable analysis navigation explains its prerequisite with a toast;
- first-run language is English and later language choices persist;
- the default portable origin is stable at `http://127.0.0.1:38921` so browser-local sessions, cached analyses, cases, language, and UI state survive executable restarts;
- journal reference detail wraps long text, starts at 50 entries, and continues by up to 100 on request;
- every analysis page has a three-node visual reading guide and an interpretation boundary;
- incident cases can be deleted and can pin evidence directly from a searchable picker;
- a two-snapshot synthetic Advisory scenario supports localized screenshots, GIF walkthroughs, MP4 walkthroughs, and page-by-page guides.

The synthetic scenario demonstrates navigation only. It is not evidence of broker pending state, consumer failure, product behavior, or root cause.
