# P0 — Golden fixture baseline

## Scope

- Added deterministic synthetic fixtures for queue, durable topic, transaction, advisory, corrupt, truncated, and false-positive cases.
- Added normalized golden JSON results and repeatable fixture tests.
- Added before/after SHA-256 verification so every scan proves that its source files were unchanged.
- Added bounded-result tests for printable strings and advisory candidates.

## Known limitation

These fixtures are deliberately small, synthetic scanner fixtures. They are not broker-generated KahaDB stores and must not be presented as proof that a structured KahaDB journal parser supports a particular ActiveMQ version. That boundary is reserved for P1 and is reported explicitly as `Unsupported` or `Unknown` when evidence is insufficient.
